# Clarify: v0.3a 生成历史记录

> 来源：specs/v0.3-history/v0.3a-history/spec.md
> 用途：将以下问题确认，得到答案后回填本文件再进入 design / plan 阶段。

## 1. 来自 [NEEDS CLARIFICATION] 的问题

### Q1. 切换历史时，对比滑动条"原图"侧是否需要还原？
- **位置**：spec.md §7 / FR-005
- **问题**：点击历史缩略图切换结果图后，前后对比滑动条左侧的"原图"侧是否需要同时还原为当时生成所用的人像图？
- **可选方案**：
  - A) 不还原——只切换结果图，原图侧保持当前上传的人像图不变（存储结构不变，只存结果图）
  - B) 还原——存储时同时保存人像图缩略图，切换时两侧同步还原（存储体积约翻倍，每条 < 60KB）
- **建议**：选 A。Brief 明确只存结果图；切换历史的核心价值是"看换装效果"，原图侧不还原用户感知影响有限；且保持存储结构简单，避免超出 localStorage 容量。
- **答复**：选 A，只切换结果图，原图侧不还原。

### Q2. 相对时间是否需要实时刷新？
- **位置**：spec.md FR-004
- **问题**：历史列表中显示的"3 分钟前"等相对时间，是仅在页面加载/列表渲染时计算一次，还是需要用定时器实时更新？
- **可选方案**：
  - A) 仅在渲染时计算一次（无定时器，最简单）
  - B) 每分钟 setInterval 刷新一次相对时间（实时但有额外开销）
- **建议**：选 A。用户查看历史通常是短时操作，时间戳精确到分钟已足够，无需实时更新增加复杂度。
- **答复**：选 B，每分钟 setInterval 实时刷新。

## 2. 技术选型澄清

### Q3. 缩略图宽度 120px 是否足够？
- **位置**：spec.md FR-002
- **问题**：FR-002 定义缩略图宽度上限为 120px，目标单条 < 30KB。实际结果图为 JPEG，压缩后大小与图片内容有关，需确认 120px / JPEG 0.85 是否满足容量约束（10 条 × 30KB = 300KB，localStorage 5MB 内有余量）。
- **可选方案**：
  - A) 120px，JPEG 0.85（spec 现有方案）
  - B) 80px，JPEG 0.8（更保守，单条约 10–15KB）
- **建议**：选 A，先按 120px 实现，若实测超出再收窄。
- **答复**：选 A，120px / JPEG 0.85，先跑起来。

### Q4. 原始尺寸结果图是否也存入 localStorage？
- **位置**：spec.md FR-002 / FR-005
- **问题**：FR-005 要求点击历史后将"原始尺寸 base64"设为 resultImage，但 FR-002 只存了缩略图。原始尺寸图（可能 200–500KB）是否也需要存入 localStorage？若不存，切换历史后放大弹窗会显示低清缩略图。
- **可选方案**：
  - A) 同时存缩略图（展示用）+ 原始图（切换还原用）——每条约 200–500KB，10 条可能达 3–5MB，接近 localStorage 上限
  - B) 只存缩略图，切换历史时 resultImage 使用缩略图——放大弹窗显示低清图，但结构简单、不占用大量存储
  - C) 存缩略图 + 中等尺寸图（Canvas 缩至 600px），平衡画质与存储
- **建议**：选 B 或 C。选 A 风险较高，10 条原图可能触碰 localStorage 5MB 上限。建议选 C（600px 中等尺寸，约 80–150KB/条，10 条约 1–1.5MB），放大弹窗画质尚可。
- **答复**：选 B，只存缩略图，切换时用缩略图展示。

## 3. 数据模型澄清

### Q5. localStorage 单条记录结构是否需要扩展字段？
- **位置**：spec.md FR-002
- **问题**：当前 spec 定义存储字段为 `id`、`timestamp`、`thumbnail`（缩略图 base64）。Q4 答案若选 B/C，还需加 `image` 字段存中等/原始尺寸图。是否还有其他字段需要存（如生成时用的服装图名称、备注等）？
- **可选方案**：
  - A) 最小集：`{ id, timestamp, thumbnail }` + 按 Q4 结论加 `image`
  - B) 扩展：再加 `label`（用户自定义备注）等字段
- **建议**：选 A，v0.3a 保持最小集，扩展留给后续版本。
- **答复**：选 A，最小集 `{ id, timestamp, thumbnail }`。
