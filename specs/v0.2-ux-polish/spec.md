# 智能换装网页 规范文档 v0.2

## 版本说明
**版本**：v0.2
**目标**：在 v0.1 交互闭环的基础上，系统性打磨上传、等待、结果三段体验，让用户从上传到看到结果全程不迷茫
**上一版本**：v0.1（完成核心交互界面）

---

## 功能列表

### 1. 人像上传区

**描述**：用户上传包含人物的照片。

**交互细节**：
- 点击选择文件
- 拖拽上传
- 粘贴上传（Ctrl+V / 截图直接粘贴）
- 支持格式：JPG, PNG, WEBP
- 文件大小限制：≤ 10MB（超过 10MB 给出内联错误提示）
- 超过 1200px 的图片在上传前自动压缩（客户端处理，无感知）
- 上传后显示缩略图预览
- 支持替换已上传的图片

**状态**：
- 空状态：虚线框 + "点击 / 拖拽 / 粘贴"提示
- 格式/大小错误：上传区下方内联红色提示（不弹 alert）
- 已完成：显示缩略图 + 悬停显示"替换"按钮


### 2. 服装上传区

**描述**：用户上传单件服装的图片。

**交互细节**：与人像上传区一致（点击 / 拖拽 / 粘贴，自动压缩，内联错误）

**状态**：与人像上传区一致


### 3. 生成按钮

**描述**：触发 AI 换装生成的核心按钮。

**交互细节**：
- 人像和服装都已上传时才可点击
- 点击后显示 loading 动画 + 动态文案
- 生成中显示"取消"文字按钮，点击可中止本次请求
- 生成完成后切换为"重新生成"样式

**状态**：
- 禁用：灰色，不可点击
- 可点击：品牌渐变色（紫→粉），悬停放大
- 生成中：灰色禁用 + 旋转动画 + 下方"取消"按钮
- 完成：切换为"🔄 重新生成"


### 4. 生成等待区

**描述**：生成过程中的等待反馈。

**交互细节**：
- 每 2 秒轮换一条分步提示语，顺序为：
  1. 正在分析人物体型...
  2. 正在识别服装轮廓...
  3. 正在融合人物与服装...
  4. 正在优化细节效果...
  5. 即将完成，请稍候...
- 进度条：基于预期时长（~8 秒）的 ease-out 曲线，最高到 90%，不假装"已完成"
- 显示"预计 15–30 秒"预期时间
- 超过 30 秒自动中止，展示"生成超时，请重试"错误


### 5. 结果展示区

**描述**：展示 AI 生成的换装效果图，支持前后对比。

**交互细节**：
- 生成完成后自动显示
- **前后对比滑动条**：左侧显示原始人物照，右侧显示换装结果，拖动分割线对比
  - 左上角标签"原图"，右上角标签"换装后"
  - 滑块默认居中（50%）
- **放大查看**：右下角放大按钮（⛶），点击全屏查看换装结果，点击遮罩或 ✕ 关闭
- 提供"下载"和"重新生成"按钮

**状态**：
- 空状态：虚线框 + 占位图 + 提示文字
- 加载中：居中旋转动画 + 分步提示语 + 进度条
- 已完成：前后对比滑动条 + 操作按钮
- 错误：红色提示框 + 错误原因 + "重试"按钮

## 用户旅程

### 旅程 1：首次用户完成一次换装
1. 打开网页，看到双栏上传区
2. 粘贴一张截图到人像区（或点击/拖拽上传）
3. 上传服装照片
4. 点击"生成换装效果"，按钮变为生成中状态
5. 等待期间看到分步提示语和进度条
6. 生成完成，结果区出现前后对比滑动条
7. 拖动滑块对比穿前穿后效果
8. 点击"下载"保存

**期望结果**：全程操作路径不超过 3 步，等待期间不焦虑，结果一目了然

### 旅程 2：用户想换一件衣服
1. 保留已上传的人像
2. 点击服装区的"替换"，上传另一件衣服
3. 点击"生成"，查看新结果

### 旅程 3：用户对效果不满意
1. 点击"重新生成"，系统用相同输入重新请求
2. 或者替换服装图片后重新生成

### 旅程 4：用户等不及想取消
1. 生成中点击"取消"文字按钮
2. 页面恢复到可重新生成的状态

## 验收标准

### 功能验收
- 上传区支持点击、拖拽、粘贴三种方式
- 格式/大小错误显示内联提示，不弹 alert
- 超过 1200px 的图片自动压缩后上传
- 生成中显示分步提示语，每 2 秒切换
- 生成中显示进度条（ease-out 曲线，最高 90%）
- 生成中可取消
- 超时（30 秒）自动中止并提示
- 结果展示前后对比滑动条
- 结果图可点击放大查看
- 结果可下载，可重新生成

### 性能验收
- 页面首屏加载 < 2 秒
- 大图压缩在客户端完成，无需服务端参与
- 等待界面不卡顿，进度条动画流畅

### 设计验收
- 上传区提示语更新为"点击 / 拖拽 / 粘贴"
- 错误提示内联展示，不打断用户流程
- 进度条颜色与品牌主色一致（紫→粉渐变）
- 对比滑动条有明确的标签和交互引导

### 隐私验收
- 图片仅在客户端压缩处理，不存储
- 生成完成后原始图片仅保留在内存（页面关闭即清除）

## 非功能需求

### 可访问性
- 上传区支持 Tab 键聚焦，Enter/Space 触发文件选择
- 上传区聚焦时显示明显的 focus 边框
- 取消按钮语义清晰

### 浏览器兼容性
- Chrome / Firefox / Safari 最新两个版本
- 移动端：iOS Safari、Android Chrome

### 响应式
- 桌面端：双栏上传区 + 居中结果区
- 手机端：单栏堆叠，上传区全宽
