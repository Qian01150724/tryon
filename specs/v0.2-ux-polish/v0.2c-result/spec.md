# Spec: v0.2c 结果体验优化

## 1. 背景与目标

v0.1 的结果展示只有一张静态图。v0.2c 目标是让用户能直观对比换装前后效果，并支持全屏放大查看细节，增强结果页的使用价值。

## 2. 用户故事 / 使用场景

- **对比查看**：用户拿到换装结果后，拖动滑条左右对比原图和结果图，判断换装效果是否满意
- **细节放大**：用户想看清衣服纹理或面部细节，点击放大按钮进入全屏弹窗，关闭后回到对比视图

## 3. 功能需求 (FR)

| 编号 | 需求 | 验证方式 |
|------|------|---------|
| FR-001 | 有结果图且有原图时，显示前后对比滑动条：换装结果图为底层，原图为上层裁切，拖动手柄控制分割线位置 | 拖动滑条，原图和结果图随手柄位置切换显示比例 |
| FR-002 | 对比区右下角有放大按钮，点击后弹出全屏弹窗展示换装结果图，点击遮罩或右上角 ✕ 关闭 | 点放大按钮后出现全屏弹窗，点 ✕ 或遮罩后弹窗消失 |

## 4. 成功标准 (SC)

| 编号 | 标准 |
|------|------|
| SC-001 | 滑条初始位置在 50%，拖动后原图和结果图按比例显示，无撕裂或错位 |
| SC-002 | 滑条区域有"原图"和"换装后"标签，分别标注左右两侧 |
| SC-003 | 放大弹窗背景为深色遮罩（≥ 80% 不透明），结果图居中显示，不超出屏幕 |
| SC-004 | 若无原图（personImage 为 null），结果图直接展示，不显示滑动条，点击图片也能触发放大 |
| SC-005 | `isZoomed` state 在弹窗关闭后重置为 false，不影响再次点击放大 |

## 5. 范围与边界

**In Scope**
- `components/ResultDisplay.tsx` 有结果时的对比滑动条和放大弹窗

**Out of Scope**
- 等待状态（加载圈、进度条）：已在 v0.2b-waiting 落地
- 上传区交互：已在 v0.2a-upload 落地
- 下载按钮：v0.1 已有，本轮不动
- 触摸/移动端手势滑动：range input 在移动端原生支持，不额外处理

## 6. 依赖与约束

- 依赖 `personImage`（原图 base64 DataURL）和 `resultImage`（结果图 DataURL）均由 `page.tsx` 通过 props 传入
- 滑动条使用透明 `<input type="range">` 覆盖在图片上，`sliderPos` state 控制 clipPath 实现图层裁切
- `isZoomed` state 管理弹窗开关，全屏弹窗用 `fixed inset-0 z-50` 覆盖整个视口

## 7. 待澄清事项

无。所有功能点已在 `components/ResultDisplay.tsx` 中完整实现，brief 与代码一致。
