# 智能换装网页 规范文档 v0.1

## 版本说明
**版本**：v0.1
**目标**：实现一个精美的换装工具界面，完成"上传人像 → 上传服装 → 点击生成 → 查看结果"的完整交互闭环
**发布日期**：待定

## 功能列表

### 1. 人像上传区
**描述**：用户上传包含人物的照片。

**交互细节**：
拖拽上传或点击选择文件
支持格式：JPG, PNG, WEBP
文件大小限制：≤ 10MB
上传后显示缩略图预览
支持替换已上传的图片
上传前显示占位提示："上传人物照片"

**状态**：
空状态：显示虚线框 + 上传提示
加载中：显示进度条或加载动画
已完成：显示缩略图 + 替换按钮


### 2. 服装上传区
**描述**：用户上传单件服装的图片（平铺或悬挂拍摄效果最佳）。

**交互细节**：
拖拽上传或点击选择文件
支持格式：JPG, PNG, WEBP
文件大小限制：≤ 10MB
上传后显示缩略图预览
支持替换已上传的图片
上传前显示占位提示："上传服装照片"

**状态**：
空状态：显示虚线框 + 上传提示
加载中：显示进度条或加载动画
已完成：显示缩略图 + 替换按钮


### 3. 生成按钮
**描述**：触发 AI 换装生成的核心按钮。

**交互细节**：
只有当人像和服装都已上传时才可点击（激活状态）
未满足条件时为禁用状态
点击后按钮变为"生成中..."并显示加载动画
生成完成后自动切换为"查看结果"或恢复为"生成"

**状态**：
禁用：灰色，不可点击
可点击：品牌色，悬停有反馈
生成中：显示加载动画 + "处理中..." 文字
完成：闪烁或高亮提示


### 4. 结果展示区
**描述**：展示 AI 生成的换装效果图。

**交互细节**：
生成完成后自动显示在结果区
显示清晰的大图预览
提供"下载"按钮（保存到本地）
提供"重新生成"按钮（使用同样的图片再次生成）
未生成时显示占位："生成的效果将显示在这里"

**状态**：
空状态：显示占位图和提示文字
加载中：显示骨架屏或 loading
已完成：显示生成图片 + 操作按钮
错误：显示友好的错误提示 + 重试按钮


### 5. 进度与状态提示
**描述**：在操作过程中向用户反馈当前状态。

**包含**：
上传进度条（百分比）
生成等待提示（"排队中..."、"处理中..."）
成功/失败的 Toast 通知
预计剩余时间（如果能获取）


## 用户旅程

### 旅程 1：首次用户完成一次换装
**场景**：一个普通消费者想看看一件衣服穿在自己身上的效果。

**步骤**：
1. 用户打开网页
2. 看到清晰简洁的界面，中间是"上传人像"和"上传服装"两个区域
3. 点击"上传人像"区域，从相册选择一张自己的照片
4. 图片上传后显示缩略图预览，区域变为"已上传 ✓"
5. 点击"上传服装"区域，选择一件衣服的图片
6. 服装上传后显示缩略图预览
7. 底部"生成"按钮从灰色变为可点击的蓝色
8. 点击"生成"，按钮变为"生成中..."并显示 loading
9. 等待 10-30 秒，结果区显示生成的换装图片
10. 用户点击"下载"保存到手机相册
11. 用户满意离开

**期望结果**：
整个流程不超过 1 分钟
用户无需看任何教程或帮助文档
生成的图片让用户有"真实穿上"的感觉


### 旅程 2：用户想换一件衣服试试
**场景**：用户对第一件衣服的效果满意，想试另一件。

**步骤**：
1. 用户保留已上传的人像
2. 点击服装区的"替换"按钮，重新上传另一件衣服
3. 点击"生成"
4. 查看新的生成结果

**期望结果**：
人像不需要重新上传
切换服装流畅，操作路径短


### 旅程 3：用户对效果不满意
**场景**：生成的效果不理想（融合不自然、穿帮等）。

**步骤**：
1. 用户点击"重新生成"按钮
2. 系统使用相同的输入重新请求生成
3. 展示新的结果
4. 如果仍不满意，用户可以尝试更换服装图片（不同角度/光线）

**期望结果**：
"重新生成"按钮一目了然
不会让用户感到困惑或无助


## 验收标准

### 功能验收
人像上传功能正常（点击 + 拖拽）
服装上传功能正常（点击 + 拖拽）
只有两张图都上传后，"生成"按钮才可点击
生成过程有清晰的 loading 反馈
生成结果可预览、可下载
"重新生成"功能正常
替换图片功能正常

### 性能验收
页面首屏加载 < 2 秒
图片上传有进度反馈
生成等待界面不卡顿
移动端上传流程顺畅

### 设计验收
整体风格简洁、现代、有科技感
上传区域视觉突出，引导明确
配色舒适、品牌统一
操作按钮大小适中，适合手指点击（移动端）
页面在手机和电脑上都有良好的布局

### 隐私验收
页面有隐私说明（图片不存储、用完即删）
没有隐藏的数据收集


## 非功能需求

### 可访问性
所有按钮有清晰的文字标签
上传区域支持键盘操作
加载状态有 ARIA 标注

### 浏览器兼容性
Chrome（最新两个版本）
Firefox（最新两个版本）
Safari（最新两个版本）
移动端：iOS Safari、Android Chrome

### 响应式
桌面端：双栏或三栏布局
平板：灵活适配
手机端：单栏堆叠布局，上传区域全宽
